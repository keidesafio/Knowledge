# 生成AI よく使われる用語まとめ [[1]](https://app.notion.com/p/AI-acca14dceb1183f286ff815f4c696f9c?pvs=21)

| 用語 (英語) | 用語 (日本語) | 解説 |
| --- | --- | --- |
| **Artificial Intelligence (AI)** | 人工知能 (AI) | 人工知能のこと。コンピュータが人間のように考えたり学んだりする技術。 |
|  | 生成 AI | 絵や文章など、新しいものを作ることができるAIのこと。 |
|  | AIエージェント | 特定の一連のタスクを自動的に実行するAIのこと。たとえば、スケジュール管理や買い物の手伝いをしてくれる。ざっくりとした命令にたいしてAIが自分で考えて実行する。 |
| **Artificial General Intelligence (AGI)** | 汎用人工知能 (AGI) | 人間のように、どんなことでも考えられる賢いAIのこと。特定のタスクや用途に縛られず、あらゆることをこなすことができる。
参考: [AGIとは？](https://app.notion.com/p/AGI-14ca1b77bdf780c0a991c76bbc492041?pvs=21) |
| **Large Language Model (LLM)** | 大規模言語モデル (LLM) | とてもたくさんの文章を学んだ結果、人と会話ができるAIのこと。
ChatGPTやClaude、Geminiなどのたくさんのモデルがある。 |
| **Machine Learning (ML)** | 機械学習 (ML) | コンピュータがたくさんのデータから学んで、だんだん賢くなる仕組みのこと。 |
|  | プロンプト | AIに何をしてほしいか伝えるための指示や質問のこと。 |
|  | モデル | AIが学んだ知識のまとめ。新しいことを考えるための仕組み。
画像生成モデルや動画生成モデル、大規模言語モデル(LLM)など様々な種類のモデルがある。 |
|  | パラメータ | 主に”LLMの賢さの指標”として用いられることが多い。高ければ高いほど賢く、その代わりに応答に時間がかかる。 |
|  | 推論 | LLM（大規模言語モデル）が学んだ知識を使って質問に答えたり、新しい文章を作ったりすること。モデルが考えた結果を出すこと。 |
|  | CoT（Chain of Thought） | LLMが複雑な質問に答えるために、考える過程を順番に説明しながら推論する方法。これにより、より正確でわかりやすい回答ができるようになる。 |
|  | チャットボット | 主に人と会話するためのAIで、質問に答えたり、話し相手になったりするもの。 |
|  | ハルシネーション | AIが知らないことを適当に作り出してしまうこと。たまに間違ったことを言う時のこと。 |
|  | ディープラーニング | AIがもっと賢く学べるように作られた特別な学習方法のこと。 |
|  | ニューラルネットワーク | 人間の脳のように考えるAIの仕組み。たくさんのつながりで成り立っている。 |
|  | アルゴリズム | コンピュータに何をどうやってやるか教える手順やルールのこと。 |
| **Diffusion** | 拡散 | AIがぼんやりしたイメージから、だんだんはっきりした絵などを作る技術。 |
|  | ファインチューニング | 既存のAIをもっと特定のことが得意になるように、追加で新しく学ばせること。 |
|  | トレーニングデータ | AIが学ぶために使う、たくさんの例や情報のこと。 |
|  | Transformer | AIが文章を上手に理解するための特別な技術の名前。 |
